# 찍꼬 (JIKKO)

가전제품이 고장났을 때 사진을 찍어 보내면 근처 수리기사님과 매칭되는 출동 서비스. 고객용 앱과 기사님(파트너)용 앱으로 구성된 양면 마켓플레이스입니다.

## 지금 상태

사용자가 설계한 두 개의 인터랙티브 프로토타입(정적 HTML, 가짜 데이터로 동작)을 그대로 배포한 상태입니다.

- `/customer.html` — 고객용: 사진 찍어서 AI 진단 → 기사님 매칭 → 결제
- `/partner.html` — 기사님용: 가입 → 온라인 전환 → 호출 수락 → 출동 → 정산

루트 `/`는 두 앱으로 가는 진입 페이지입니다.

이 프로토타입들은 `public/` 폴더에 그대로 들어있고, 전부 자체 완결된 HTML+CSS+JS라 백엔드 없이도 화면 흐름을 그대로 체험할 수 있습니다. 실제 서비스로 전환하려면 Supabase(인증/DB/실시간 콜보드)와 결제 연동이 필요합니다 — 자세한 계획은 `CLAUDE.md` 참고.

## 로컬 실행

```bash
npm install
npm run dev
```

## 배포

Vercel에 새 프로젝트로 연결 → `main` 브랜치 자동 배포.
